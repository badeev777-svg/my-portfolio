Telegram Bot / AI Agent

Aleks Agent

Telegram-бот для управления кодинг-агентом (Claude Agent SDK) прямо с телефона. Пишу код, читаю логи и запускаю деплой из чата — без ноутбука под рукой. Работает на отдельном VPS.

Python Telegram Bot API Claude Agent SDK asyncio SQLite systemd / VPS
Функции

Что умеет бот

💬

Чат с агентом

Пишешь задачу текстом в Telegram — агент читает код, вносит правки, запускает команды и присылает результат.

📁

Мультипроектность

Список проектов на VPS и переключение активного через /projects и /project — у каждого своя сессия и история.

🧠

Память сессии

Диалог с агентом продолжается по session_id — не нужно каждый раз объяснять контекст заново.

⚠️

Подтверждение рисков

Опасные действия (git push, sudo, docker, systemctl restart, rm -rf, правки .env/secrets) требуют инлайн-подтверждения кнопкой перед выполнением.

🔒

Авторизация

Бот отвечает только владельцу по allowed_user_id — сторонний доступ к агенту и файлам сервера исключён.

🔁

Устойчивость к сбоям

Повторные попытки с экспоненциальной задержкой на временных ошибках API, без бессмысленных ретраев при биллинг-ошибках.

Технологический стек

Используемые технологии

🐍

Python 3.11+

Асинхронный backend на asyncio

💬

python-telegram-bot

Обработка сообщений и inline-кнопок подтверждения

🤖

Claude Agent SDK

Кодинг-агент, читающий и правящий проект по запросу

🗄️

SQLite (StateStore)

Активный проект, session_id и настройки пользователя

🛡️

Risk-фильтр

Разбор bash-команд на риск: git push, sudo, docker, rm -rf и вложенные вызовы

⚙️

systemd

Бот работает как сервис на VPS, автозапуск и логирование в файл

Управление

Команды бота

/projects
Показать список доступных проектов на сервере.
/project <имя>
Сделать проект активным для текущего диалога.
[текст]
Любое сообщение — задача агенту в контексте активного проекта.
✅ / ❌
Инлайн-кнопки подтверждения перед рискованным действием агента.
